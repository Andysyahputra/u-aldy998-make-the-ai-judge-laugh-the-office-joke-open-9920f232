# Make the AI Judge Laugh: the Office Joke Open

A make.fun entry for competition
`u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232`.

## What it does

`main.py` writes one original single-line office joke to
`/output/entry.txt` when run. It is fully deterministic: no
randomness, no network, no input, no files outside the repo.

## The joke

> I renamed the weekly sync 'optional' and attendance tripled — turns out the only thing worse than a meeting is missing one.

123 characters, one line, valid UTF-8.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
